📢 公告

分「系统公告」与「部门公告」两类。内部富文本编辑，图片、视频、文件拖拽上传，按部门范围定向投递，发布后原地下架重发。

💬 私信

一对一与多人群组会话，支持转发、在线状态、未读提醒。系统通知与申诉回执走同一条链路，全程留痕。

👥 成员

成员档案、部门归属与职级链。权值调整仅对经理级以上开放；注销申请由管理员审核，通过后账号即时停用。

📁 项目

发起、上报、审批三段走完才算立项。支持「监督陪伴员」机制，可见范围按上下级计算，各级每日提交进度汇报。

🕐 打卡日历表

以凌晨四点为分界自动打卡，节假日与调休逐年标注，可在日期上添加个人日程并打勾；打卡日历与项目日历一键切换。

📊 考核

考勤分、月度考题、晋升考题三个维度汇总为考核分，与权值和工资条直接挂钩，每月自动结算生成工资明细。

🧩 软件

系统内置的代码编辑器，自带 Python 与 C++ 环境。新建、打开、保存、运行都在系统里完成，不用另装工具。

⚙️ 设置

个人资料、账号安全与数据导出。哪些信息对谁可见，都在这里逐项设定。

关于我们

归零棱镜（PrismZeroGroup）是从乐山起步的学生团队。母体是深零科模，下设科研部与设计部两条技术线；财务部管钱，法务部管规矩。 我们做的东西不长在别人的框架上——代码自己写，系统自己搭，规则自己定。
